# KM Kits Africa — Project Scaffold

This repository contains a minimal scaffold for the KM Kits Africa service projects website used for the W06 project.

Structure:
- `index.html` — home page and projects list
- `styles/main.css` — main stylesheet
- `scripts/main.js` — project rendering and simple logic
- `images/` — place project images here (e.g., `project-photo.jpg`)

Notes:
- All files and folders use lowercase naming with hyphens.
- Images should use native lazy loading for below-the-fold content.
